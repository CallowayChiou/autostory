AutoStory 隱私權政策

最後更新：2026 年 10 月 30 日

適用範圍

AutoStory 是個人自用的影片製作與上傳工具，僅由開發者本人使用，不對外提供服務。

存取的資料

本工具透過 Google OAuth 取得本人 YouTube 帳號的授權，僅用於將本人製作的影片及其標題、說明、縮圖上傳至本人的 YouTube 頻道，以及讀取上傳結果與頻道基本資訊。

資料的儲存與分享

OAuth 授權憑證僅儲存在開發者本人的電腦上，不會上傳至任何伺服器，也不會與任何第三方分享、出售或轉讓。本工具不蒐集其他使用者的任何個人資料。

撤銷授權

可隨時至 Google 帳戶的「第三方應用程式和服務」頁面（https://myaccount.google.com/permissions）撤銷本工具的存取權限。

相關條款

本工具使用 YouTube API 服務。使用時適用 YouTube 服務條款 與 Google 隱私權政策。本工具對 Google API 取得之資料的使用，遵守 Google API 服務使用者資料政策，包括「有限使用」規定。
