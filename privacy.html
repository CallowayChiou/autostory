AutoStory 隱私權政策

最後更新：2026 年 10 月 31 日

適用範圍

AutoStory 是個人自用的影片製作與上傳工具，僅由開發者本人使用，不對外提供服務。

存取的資料

本工具透過 Google OAuth 取得本人 YouTube 帳號的授權，僅用於將本人製作的影片及其標題、說明、縮圖上傳至本人的 YouTube 頻道，以及讀取上傳結果與頻道基本資訊。

資料的儲存與分享

OAuth 授權憑證僅儲存在開發者本人的電腦上，不會上傳至任何伺服器，也不會與任何第三方分享、出售或轉讓。本工具不蒐集其他使用者的任何個人資料。

撤銷授權

可隨時至 Google 帳戶的「第三方應用程式和服務」頁面（https://myaccount.google.com/permissions）撤銷本工具的存取權限。

相關條款

本工具使用 YouTube API 服務。使用時適用 YouTube 服務條款 與 Google 隱私權政策。本工具對 Google API 取得之資料的使用，遵守 Google API 服務使用者資料政策，包括「有限使用」規定。

資料刪除

本工具只在開發者本人的電腦上保存 OAuth 授權憑證與上傳紀錄，不保存其他任何 YouTube 使用者的資料。撤銷授權後憑證即失效，開發者會同時刪除本機的憑證檔。若對透過本工具取得的資料有刪除需求，請來信 linglinglingyo@gmail.com，將於 7 天內刪除。

聯絡方式

linglinglingyo@gmail.com

AutoStory Privacy Policy (English)

Last updated: October 31, 2026

Scope

AutoStory is a personal desktop tool used only by its developer to produce videos and upload them to the developer's own YouTube channel. It is not offered to anyone else.

YouTube API Services

AutoStory uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy. AutoStory's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data accessed

Through Google OAuth, AutoStory accesses only the developer's own YouTube account, to upload the developer's videos with their titles, descriptions and thumbnails, and to read upload results and basic channel information. It does not collect any data from other users.

Storage and sharing

OAuth credentials are stored only on the developer's own computer. They are never uploaded to any server, and are never shared, sold or transferred to third parties.

Revoking access

Access can be revoked at any time on the Google security settings page.

Data deletion

After access is revoked, the local credential file is deleted. AutoStory does not store any other YouTube user's data. To request deletion of any data obtained through AutoStory, email linglinglingyo@gmail.com; requests are handled within 7 days.
